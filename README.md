# lists-practice

Автор: Михайлюк Юрій, група МІТ-1026г  
Курс: Основи інформатики та програмування, Лекція 2.5 «Масиви та списки».

Вісім стандартних операцій зі списками як функції на власних даних (бали студентів, температури тижня). Кожна операція — окремий коміт у гілці `feature-lists`, потім гілку злито в `main`.

## Файли

- `list_ops.py` — функції операцій і демонстрація (`python3 list_ops.py`)
- `test_list_ops.py` — тести (`python3 test_list_ops.py`)
- `pitfalls.py` — п'ять пасток зі списками на коді
- `report.md` — звіт
